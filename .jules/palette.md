## 2026-07-15 - Focus Ring Visibility
**Learning:** Using `focus:` for focus rings causes visual distraction for mouse users when they click a button.
**Action:** Always use `focus-visible:` for focus styles so they only appear during keyboard navigation, ensuring an accessible yet pleasant experience for all users.
